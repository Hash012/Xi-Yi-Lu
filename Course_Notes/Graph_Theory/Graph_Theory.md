2. 图的定义：
    1. 预备知识：
        - 无序积
        - 笛卡尔积 -- $\empty$ 与任何集合的笛卡尔积是空集，所以 A = B 不是 A $\times$ B = B $\times$ A的充要条件
        - 多重集合
    2. 无向图和有向图的定义：
        
        __定义1.1__ 一个无向图是一个有序的二元组<V，E>,记作 $\textbf{G}$，其中

        （1）V $\neq \empty$ 称为顶点集，其元素称为顶点或结点。
        
        （2）E称为边集，它是无序积V&V的多重子集，其元素称为无向边，简称边。
        
        __定义 1.2__ 一个有向图是一个有序的二元组<V，E>，记作 $\textbf{D}$，其中
        （1）V $\neq \empty$ 称为顶点集，其元素称为顶点或结点。
        （2）E为边集，它是笛卡儿积V×V的多重子集，其元素称为有向边，简称边。

        - 顶点集V $\neq \empty$ ，是在不发生运算时定义的要求，运算中可能为空。
    
    3. 简单概念和规定：
    - $G$表示无向图，但有时用$G$泛指图(无向的或有向的)。$D$通常表示有向图。
    - $V(G)，E(G)$分别表示$G$的顶点集和边集。不发生混淆的情况下可用V和E表示。
    - 若$|V(G)|＝n$，则称$G$为$n$阶图。如果$|V(G)|=n$,$|E(G)|=m$,$G$也称为$(n,m)$图。
    - 若$|V(G)|$与$|E(G)|$均为有限数，则称G为有限图。
    - 若边集 $E(G)＝\empty$ ，则称$G$为零图。此时，又若$G$为$n$阶图，则称$G$为$n$阶零图，记作$N_n$，特别地，称$N_1$为平凡图
    - $K_n代表 n 阶完全图（Complete Graph of order n）。简单来说，它是指一个拥有 n 个顶点，且每两个顶点之间都恰好有一条边相连的图。$

    4. 基本概念：
        1. __空图__ $\empty$：在图的定义中规定顶点集V为非空集，但在图的运算中可能产生顶点集为空集的运算结果，为此规定顶点集为空集的图为空图，并将空图记为$\empty$。
        2. __标定图__ :将图的集合定义转化成图形表示之后，常用$e_k$表示无向边(vi,vj)（或有向边<vi,vj>），并称顶点或边用字母标定的图为标定图，否则称为非标定图。
        3. __基图__ : 将有向图各有向边均改成无向边后的无向图称为原来图的基图。
        4. __关联与关联次数、环、孤立点__:  
            - 设$G=<V,E>$为无向图，$e_k＝(v_i,v_j)∈E$，称$vi,vj$为$e_k$的端点，$e_k$与$v_i$或$e_k$与$v_j$是彼此相关联的。
            - 若$vi \ne vj$，则称$e_k$与$v_i$或$e_k$与$v_j$的关联次数为1。
            - 若$vi＝vj$，则称$e_k$与$v_i$的关联次数为2，并称$e_k$为$G$中的环。
            - 任意的$v_l∈V$，若$v_l \ne vi$且$v_l \ne vj$，则称$e_k$与$v_l$的关联次数为0。
            - 无论在无向图中还是在有向图中，无边关联的顶点均称为孤立点。
            - 区别 __环__ 和 __回路__: 一条边的两个端点一模一样才是环。


        5. __相邻与邻接__:
            
            $设\textbf{无向图} G＝<V，E>，vi，vj∈V，e_k，e_l∈E$。
            - （点相邻）若$\exist e_t∈E，使得e_t＝(v_i，v_j)，则称v_i与v_j是相邻的。$
            - （边相邻）$若e_k与e_l至少有一个公共端点，则称e_k与e_l是相邻的。$

            $设\textbf{有向图} D＝<V，E>，v_i，v_j∈V，e_k，e_l∈E。$
            - $若\exist e_t∈E，使得e_t＝<v_i，v_j>，则称vi为e_t的始点，v_j为et的终点，并称v_i \textbf{邻接到} v_j，v_j\textbf{邻接于} v_i$
            - $若e_k的终点为e_l的始点，则称e_k与e_l相邻$
